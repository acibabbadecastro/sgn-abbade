## ⏰ 14:30 - 15:30 (60 MINUTOS)
### MÓDULO 1: HTML BÁSICO

**14:30 - 14:45 (TEORIA)**
- O que é HTML (linguagem de marcação)
- Estrutura básica de uma página
- Explicar tags: <html>, <head>, <body>
- Mostrar exemplo na tela

**14:45 - 15:10 (PRÁTICA 1)**
- Abrir bloco de notas no computador
- Criar estrutura básica juntos:
```html
<!DOCTYPE html>
<html>
<head>
    <title>Meu Perfil</title>
</head>
<body>
    <!-- Conteúdo aqui -->
</body>
</html>
```
- Salvar como "index.html"
- Abrir no navegador (duplo clique)

**15:10 - 15:30 (PRÁTICA 2 - PERSONALIZAÇÃO)**
- Cada um adiciona:
  * <h1> com seu nome
  * <p> com idade
  * <p> com bairro
  * <p> com hobby
- Você circula ajudando individualmente
- Corrigir erros de digitação
- Testar no navegador

**DICAS:**
- Falar devagar
- Repetir comandos
- Perguntar se entenderam
- Celebrar pequenas conquistas

## ⏰ 15:45 - 16:45 (60 MINUTOS)
### MÓDULO 2: CSS BÁSICO

**15:45 - 16:00 (TEORIA)**
- O que é CSS (estilização)
- Como adicionar (tag <style> no head)
- Mostrar propriedades: color, background-color
- Demonstrar mudanças ao vivo

**16:00 - 16:30 (PRÁTICA 3 - ESTILIZAÇÃO)**
- Adicionar <style> no head
- Cada um personaliza:
```css
<style>
    body {
        background-color: [escolha deles];
    }
    h1 {
        color: [escolha deles];
        text-align: center;
    }
</style>
```
- Testar diferentes cores
- Mostrar ferramenta: https://htmlcolorcodes.com
- Incentivar criatividade

**16:30 - 16:45 (PRÁTICA 4 - AVANÇADO)**
- Adicionar mais estilos:
  * font-size
  * border-radius
  * padding
- Mostrar resultado final
- Comparar: antes x depois do CSS

## ⚠️ DICAS IMPORTANTES

### **Se alguém não entender:**
1. Pare e explique novamente
2. Use outras palavras
3. Mostre na tela passo a passo
4. Peça para repetir com você

### **Se der erro no código:**
1. Não se preocupe, erros são normais
2. Mostre que você também erra
3. Corrija junto com a pessoa
4. Explique o que estava errado

### **Se acabar antes do tempo:**
- Mostrar mais exemplos de sites
- Falar sobre carreira em TI
- Deixar praticarem mais
- Perguntar se têm dúvidas

### **Se atrasar:**
- Pule partes menos essenciais
- Foque no projeto final
- CSS pode ser mais rápido
- O importante é cada um ter um site funcionando
