### **VÍDEO 2: HTML Básico (8 min)**
**Título:** "Criando Sua Primeira Página HTML"

**Roteiro:**
- [ ] 0:00-1:00 - O que é HTML (linguagem de marcação)
- [ ] 1:00-2:00 - Abrindo o Bloco de Notas
- [ ] 2:00-4:00 - Estrutura básica: html, head, body
- [ ] 4:00-6:00 - Tags essenciais: h1, p, img
- [ ] 6:00-7:00 - Salvando e abrindo no navegador
- [ ] 7:00-8:00 - Mostrando resultado final

**Exemplo prático:**
```html
<!DOCTYPE html>
<html>
<head>
    <title>Meu Site</title>
</head>
<body>
    <h1>Olá, eu sou [Nome]!</h1>
    <p>Este é meu primeiro site.</p>
</body>
</html>
```

### **VÍDEO 3: CSS Básico (8 min)**
**Título:** "Deixando Seu Site Bonito com CSS"

**Roteiro:**
- [ ] 0:00-1:00 - O que é CSS (estilização)
- [ ] 1:00-2:30 - Como adicionar CSS ao HTML
- [ ] 2:30-4:30 - Cores: color e background-color
- [ ] 4:30-6:00 - Fontes: font-size e font-family
- [ ] 6:00-7:00 - Alinhamento: text-align
- [ ] 7:00-8:00 - Mostrando antes e depois

**Exemplo prático:**
```css
<style>
    body {
        background-color: #f0f0f0;
        font-family: Arial;
    }
    h1 {
        color: blue;
        text-align: center;
    }
</style>
```

## 🎥 PRODUÇÃO DOS VÍDEOS

### **Equipamento necessário:**
- [ ] Celular com câmera boa OU webcam do notebook
- [ ] Microfone (pode ser do celular)
- [ ] Tripé ou apoio para deixar câmera estável
- [ ] Editor de vídeo simples (CapCut, InShot, ou gravador de tela)

### **Como gravar:**
1. **Gravador de tela:** Use OBS Studio (gratuito) ou gravador do celular
2. **Áudio:** Fale claramente, ambiente silencioso
3. **Tela:** Aumente o tamanho da fonte no editor de texto
4. **Cortes:** Edite para remover erros e pausas longas

### **Tempo estimado de produção:**
- Roteirização: 1h (já está pronto acima!)
- Gravação: 2-3h (todos os 6 vídeos)
- Edição: 2-3h
- **Total:** 6-7 horas de trabalho
