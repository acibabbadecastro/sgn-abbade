### **Fase 1: Fundamentos (Semanas 1-4)**

- Funções e módulos
- Primeiros scripts práticos

### **Fase 2: Manipulação de Dados (Semanas 5-8)**
- Pandas (DataFrames)
- NumPy (arrays, matrizes)
- Leitura de arquivos (CSV, Excel)
- Limpeza de dados

### **Fase 3: Visualização (Semanas 9-12)**
- Matplotlib (gráficos básicos)
- Seaborn (gráficos estatísticos)
- Plotly (interativos)
- Dashboards simples

### **Fase 4: Estatística (Semanas 13-16)**
- Estatística descritiva
- Probabilidade básica
- Testes de hipótese (conceitos)
- Correlação e regressão simples

### **Fase 5: Machine Learning Intro (Semanas 17-20)**
- Conceitos de ML
- Scikit-learn (básico)
- Modelos simples (regressão linear, árvores)
- Avaliação de modelos

### **Fase 6: Projetos Práticos (Semanas 21+)**
- Análise de dados real
- Pequenos projetos
- Portfólio GitHub
- Certificações
