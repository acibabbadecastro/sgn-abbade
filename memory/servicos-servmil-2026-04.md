- Analisar se há scripts de logon configurados no Active Directory
- Verificar se há atalhos em `%APPDATA%\Microsoft\Windows\Recent` apontando para locais diferentes
- Considerar usar DFS (Distributed File System) para unificar acessos se for ambiente maior
