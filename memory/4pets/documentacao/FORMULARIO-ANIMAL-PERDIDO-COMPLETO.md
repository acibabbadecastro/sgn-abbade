## 💾 ONDE GUARDAR OS DADOS

### Opção 1: Google Sheets (Mais Simples)
- Cada formulário vira uma linha na planilha
- Fotos vão para pasta no Google Drive
- Link direto: `docs.google.com/spreadsheets/...`

### Opção 2: Firebase (Mais Completo)
- Banco de dados em tempo real
- Fotos em Firebase Storage
- Mostra no site automaticamente
- Gratuito até certo limite

### Opção 3: Supabase (Alternativa)
- Similar ao Firebase
- Open source
- Gratuito
