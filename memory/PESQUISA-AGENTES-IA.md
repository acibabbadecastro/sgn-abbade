## 📊 **LINHAS DE PESQUISA**

### **1. Agentes com Memória Persistiva**
- Sistemas que mantêm contexto entre sessões
- Memory banks e vector databases
- RAG (Retrieval-Augmented Generation)
- Long-term memory em LLMs

### **2. Agentes Online (Cloud)**
- Modelos hospedados em nuvem
- APIs: OpenAI, Anthropic, Google, Minimax
- Vantagens: Escalabilidade, poder de processamento
- Desvantagens: Latência, custo, privacidade

### **3. Agentes Offline (Local)**
- Modelos rodando localmente (Ollama, LM Studio, etc.)
- Vantagens: Privacidade total, sem custo por token, baixa latência
- Desvantagens: Hardware limitado, modelos menores

### **4. Arquitetura Híbrida**
- Cloud para tarefas complexas
- Local para tarefas rotineiras/sensíveis
- Roteamento inteligente de requests
