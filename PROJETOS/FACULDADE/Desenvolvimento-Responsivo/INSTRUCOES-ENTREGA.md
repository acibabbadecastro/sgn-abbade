## 📸 COMO GERAR O PDF PARA ENTREGA

### Opção 1: Navegador (Recomendado)

1. **Abra o arquivo HTML no navegador:**
   ```bash
   # No servidor (se tiver interface gráfica)
   firefox /root/.openclaw/workspace/PROJETOS/FACULDADE/Desenvolvimento-Responsivo/relatorio-para-pdf.html
   
   # OU copie para seu computador e abra
   ```

2. **Imprima como PDF:**
   - Pressione `Ctrl+P` (ou Cmd+P no Mac)
   - Em "Destino", escolha **"Salvar como PDF"**
   - Ajuste margens se necessário
   - Clique em "Salvar"
   - Nomeie como: `Aula-Pratica-2-Desenvolvimento-Responsivo.pdf`

3. **Teste a página responsiva:**
   - Abra `index.html` no navegador
   - Redimensione a janela
   - Tire prints em 4 tamanhos diferentes:
     - 1280px+ (desktop)
     - 768px (tablet)
     - 480px (telas pequenas)
     - <480px (smartphone)

4. **Insira as imagens no PDF:**
   - No relatório, há espaço para 4 imagens
   - Cole os prints nas seções correspondentes
   - Salve o PDF final

---

### Opção 2: Replit (Online)

1. Acesse https://replit.com
2. Crie um novo projeto "HTML, CSS, JS"
3. Copie o conteúdo de `index.html` para o `index.html` do Replit
4. Copie o conteúdo de `style.css` para o `style.css` do Replit
5. Clique em "Run"
6. Teste redimensionando a janela de preview
7. Tire screenshots dos 4 breakpoints
8. No relatório, inclua os prints

---

### Opção 3: VS Code + Live Server

1. Abra a pasta no VS Code
2. Instale a extensão "Live Server"
3. Clique com botão direito em `index.html`
4. Escolha "Open with Live Server"
5. Teste a responsividade
6. Tire screenshots
7. Gere o PDF conforme Opção 1

## 💡 DICAS

1. **Para redimensionar no Chrome/Firefox:**
   - Pressione F12 (DevTools)
   - Clique no ícone de dispositivo (Ctrl+Shift+M)
   - Digite as larguras: 1280, 768, 480, 375
   - Tire print de cada uma

2. **Para juntar imagens no PDF:**
   - Use LibreOffice Writer ou Google Docs
   - Insira o texto do relatório
   - Cole as imagens nos locais indicados
   - Exporte como PDF

3. **Para reduzir tamanho do PDF:**
   - Use https://ilovepdf.com/pt/comprimir_pdf
   - Ou https://smallpdf.com/pt/comprimir-pdf
