1. OBJETIVO DA ATIVIDADE

Implementar a responsividade em uma página web, garantindo boa usabilidade em diferentes dispositivos (desktop, tablet, smartphone) através de Media Queries CSS.

2. DESCRIÇÃO DOS PROCEDIMENTOS

2.1 Ferramentas Utilizadas

  • Editor: VS Code / Replit (https://replit.com)
  • Linguagens: HTML5 e CSS3
  • Técnica: Media Queries com breakpoints

2.2 Breakpoints Implementados

BP1 ≥1280px Desktop 6 colunas
BP2 768px - 1279px Tablet 3 colunas
BP3 480px - 767px Telas pequenas 2 colunas
BP4 <480px Smartphone 1 coluna

3.2 Arquivo: style.css (Media Queries)

/* Breakpoint 1280px+ - Desktop (6 colunas) */
@media (min-width: 1280px) {
    .bloco {
        flex: 0 0 calc(16.666% - 20px);
    }
}

/* Breakpoint 768px+ - Tablet (3 colunas) */
@media (min-width: 768px) and (max-width: 1279px) {
    .bloco {
        flex: 0 0 calc(33.333% - 20px);
    }
}

/* Breakpoint 480px+ - Telas pequenas (2 colunas) */
@media (min-width: 480px) and (max-width: 767px) {
    .bloco {
        flex: 0 0 calc(50% - 20px);
    }
}

/* Breakpoint < 480px - Smartphone (1 coluna) */
@media (max-width: 479px) {
    .bloco {
        flex: 0 0 100%;
    }
}

4. EXPLICAÇÃO TÉCNICA

A responsividade web permite que uma página se adapte automaticamente ao tamanho da tela do dispositivo do usuário, garantindo boa usabilidade em desktops, tablets e smartphones.

As Media Queries são regras CSS que aplicam estilos condicionalmente baseadas em características do dispositivo (largura, altura, orientação, etc.).

Breakpoint 1 (≥1280px): Desktop - 6 colunas (16.666% cada bloco)
Breakpoint 2 (768px - 1279px): Tablet - 3 colunas (33.333% cada bloco)
Breakpoint 3 (480px - 767px): Telas pequenas - 2 colunas (50% cada bloco)
Breakpoint 4 (<480px): Smartphone - 1 coluna (100% largura)
