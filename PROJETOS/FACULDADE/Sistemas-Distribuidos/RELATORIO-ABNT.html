1 INTRODUÇÃO

Este trabalho foi desenvolvido para a disciplina de Sistemas Distribuídos com o objetivo de aplicar conceitos fundamentais de sincronização de relógios, conteinerização, virtualização e análise de protocolos de rede.

As atividades práticas realizadas foram:

  • Sincronização de relógios utilizando servidor NTP nos sistemas Windows 10 e Linux (WSL)
  • Orquestração de contêineres com Docker Swarm (5 réplicas do servidor Apache)
  • Análise de tráfego de rede com o Wireshark
  • Criação de máquina virtual com Oracle VirtualBox

Foi utilizado o Windows 10 como sistema operacional base, WSL (Windows Subsystem for Linux) para os comandos Linux e Docker Desktop para a orquestração dos contêineres.

1.1 OBJETIVOS

O objetivo geral deste trabalho é aplicar na prática os conceitos de sistemas distribuídos, compreendendo a importância da sincronização temporal, orquestração de serviços, análise de rede e virtualização.

Os objetivos específicos incluem:

  • Configurar sincronização de relógios com servidor NTP
  • Implementar cluster Docker Swarm com múltiplas réplicas
  • Capturar e analisar tráfego de rede com Wireshark
  • Criar e configurar máquina virtual com VirtualBox

2 FUNDAMENTAÇÃO TEÓRICA

2.1 SINCRONIZAÇÃO DE RELÓGIOS COM NTP

O Network Time Protocol (NTP) é um protocolo utilizado para sincronização de relógios em redes de computadores. A sincronização temporal é essencial em sistemas distribuídos para garantir consistência em operações como autenticação, logging e transações.

No Windows 10, a sincronização é realizada através do serviço W32Time, enquanto no Linux utiliza-se o daemon NTP ou systemd-timesyncd.

2.2 CONTEINERIZAÇÃO COM DOCKER

Docker é uma plataforma de virtualização a nível de sistema operacional que permite a criação e execução de contêineres. O Docker Swarm é o orquestrador nativo do Docker, permitindo gerenciar clusters de contêineres com múltiplas réplicas de serviços.

2.3 ANÁLISE DE PROTOCOLOS COM WIRESHARK

Wireshark é um analisador de protocolos de rede que permite capturar e inspecionar pacotes em tempo real. É uma ferramenta essencial para troubleshooting, análise de segurança e compreensão do funcionamento de protocolos de rede.

2.4 VIRTUALIZAÇÃO COM VIRTUALBOX

Oracle VirtualBox é um software de virtualização que permite executar múltiplos sistemas operacionais em um único hardware físico. A virtualização é fundamental em ambientes de desenvolvimento, teste e produção.

Este trabalho foi desenvolvido através de abordagem prática, utilizando os seguintes recursos:

4 RESULTADOS E DISCUSSÃO

4.1 SINCRONIZAÇÃO NTP

No Windows 10, foram executados os seguintes comandos no Prompt de Comando como Administrador:

w32tm /config /syncfromflags:manual /manualpeerlist:0.pool.ntp.org
net stop w32time
net start w32time
w32tm /resync /rediscover
