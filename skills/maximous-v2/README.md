## 🌟 O QUE É O MAXIMOUS?

Maximous é um **sistema inteligente de preservação de contexto** para assistentes de IA que:

✅ **Nunca deixa você perder informações importantes**  
✅ **Aprende suas preferências automaticamente**  
✅ **Economiza até 70% dos tokens** em cada sessão  
✅ **Organiza dados de forma inteligente** por categoria e valor  
✅ **Sincroniza em múltiplas nuvens** (GitHub, Google Drive, Dropbox, local)

> 💡 *"É como ter um cérebro externo para sua IA - ela nunca esquece o que importa"*

---

## 🚀 POR QUE USAR MAXIMOUS?

### 😰 Sem Maximous:
- ❌ Perde contexto a cada `/new`
- ❌ Repete preferências constantemente
- ❌ Gasta tokens com informações redundantes
- ❌ Dados desorganizados e difíceis de encontrar
- ❌ Sessões longas = performance degradada

### 😍 Com Maximous:
- ✅ Contexto 100% preservado entre sessões
- ✅ Preferências aprendidas automaticamente
- ✅ Economia de até **70% dos tokens**
- ✅ Dados categorizados e indexados
- ✅ Sessões otimizadas com inteligência

## 🛠️ INSTALAÇÃO RÁPIDA

```bash
# Clone o repositório
git clone https://github.com/acibabbadecastro/maximous.git

# Entre na pasta
cd maximous

# Configure suas preferências
bash core/preferences-config.sh

# Ative o sistema
bash scripts/dashboard-status.sh

# Pronto! Maximous está rodando 🚀
```

---

## 🎮 COMO USAR

### Dashboard em Tempo Real
```bash
# Ver status completo
bash scripts/dashboard-status.sh

# Ver economia de tokens
bash scripts/memory-organizer.sh economy
```

### Organizar Memórias
```bash
# Processar e categorizar automaticamente
bash scripts/memory-organizer.sh full

# Ver estrutura organizada
bash scripts/memory-organizer.sh structure
```

### Backup Multi-Cloud
```bash
# Sync para todos os destinos
bash scripts/multi-cloud-sync.sh all

# Apenas DATASVR (local)
bash scripts/multi-cloud-sync.sh datasvr
```
